# 旋转 IMM 直接迁移说明

本次修改针对桌面 QYG_QDVision2026，直接启用旋转 IMM，不设旁路观察模式。

## 接线

`观测 → 主 EKF 几何估计 + IMM 旋转预测 → IMM 辅助板号匹配 → 消除板号偏移的相位更新 → Target(yaw, v_yaw, a_yaw) → 各候选板 → 命中时刻预测 / MPC 采样`

- 主 EKF 保持 12 维，继续估计位置、平移速度、半径和高度。
- IMM 的三个旋转状态独立保存，不写回主 EKF 的状态和协方差。
- 匹配时，将主 EKF 的几何状态与 IMM 预测相位组合为关联候选；两个估计器交叉相关未知，协方差使用分块对角近似。
- IMM 启用时执行已有配置中的 max_match_yaw_diff 朝向门限，并拒绝非有限关联距离；关闭 IMM 保留旧匹配路径。
- 每帧从已匹配观测中选面积最大的一块，减去板号 × 2π/N 后更新 IMM 一次。
- 普通目标直接发布 IMM 的 yaw、v_yaw 和 a_yaw；前哨站仍沿用原旋转先验，a_yaw 为 0。
- 丢检继续预测，重建目标和 LOST 时清除 IMM；空观测重置进入 LOST。
- 四板图像重投影和三维可视化使用实际发布的相位。

## 下游

Target.msg 新增 float64 a_yaw，单位 rad/s²。它表示目标旋转角加速度，与车体平移加速度、云台控制加速度不同。

候选板 State 从 9 维扩为 10 维，在末尾索引 9 追加 a_yaw，原有索引不变。
原整车 EKF 的索引 11 仍是 dz2。

统一预测：
- θ(t+τ) = wrap(θ + ωτ + 0.5ατ²)
- ω(t+τ) = ω + ατ

本版下游使用当前融合状态的恒角加速度外推。MPC 的负时间回退和正时间推进使用相同公式；参考采样不调用 IMM 更新。
最近板选择规则、弹道模型、MPC 权重和约束、串口协议均沿用原实现。
当前源码没有旧等板分支，本次没有新增等板功能。

## 配置

位置：src/rm_bringup/config/node_params/armor_solver_params.yaml，tracker.imm。

enabled 默认 true。设置 false 并重启节点后恢复主 EKF 的旋转输出，a_yaw 为 0。
配置在节点启动时读取，不承诺运行中动态修改生效。
保留杭电离散步噪声语义，因此 Q 和模型转移表现与实际帧率有关；当前数值为迁移起点，尚未经本车数据调参。

- r_yaw 是姿态朝向观测方差（rad²），不是视线角误差。
- alpha_decay 表示每个预测步保留的角加速度比例，越小回零越快。
- dt_max 控制分步长度，不截掉实际经过时间；小于 dt_min 的正时间不会被放大。
- 非正时间差、非有限时间差和超过跟踪重置阈值的时间差触发节点跟踪重置。

## 与杭电原实现的差别

参考 HDU-PHOENIX/Sc_vision，固定提交：
https://github.com/HDU-PHOENIX/Sc_vision/tree/e0e7c00e1a97ccf6a17df89d782b05e26711890d

保留三模型交互、概率更新、Joseph 协方差更新和异常量测门控。
本次修正：
1. 混合状态跨 ±π 时，协方差中的相位差按圆周角计算。
2. 状态转移中的加速度衰减只应用一次，与 F 的传播一致。
3. 时间不再直接 clamp 后丢失或增加实际经过时间。
4. 节点明确读取实际使用的 q_v/q_alpha 标量参数，并检查有限值和转移矩阵行和。
5. 增加本工程的匹配、消息、预测与可视化接线。
